## 🌟 Overview

This **React Developer Portfolio** is a modern, component-based web application built to showcase projects, skills, and professional experience in an interactive and visually appealing way.

Unlike static HTML portfolios, this project leverages **React’s reusable components**, **Tailwind CSS utility-first styling**, and **Framer Motion animations** to deliver a smooth, app-like user experience.  
The portfolio is designed with **dashboard-style sections**, **animated project cards**, and **responsive layouts**, making it suitable for recruiters, clients, and technical audiences.

---

## ✨ Key Features

### 🎨 UI / UX
- **Modern Glassmorphism UI**  
  Subtle blur effects, gradients, and soft shadows for a premium look.
- **Animated Interactions**  
  Page transitions, hover effects, and card animations using Framer Motion.
- **Responsive Design**  
  Fully optimized for mobile, tablet, and desktop screens.
- **Dark Theme First**  
  Developer-friendly dark UI with consistent color system.

### 💼 Portfolio Features
- **Project Cards with Flip Animation**  
  Compact cards showing overview on front and actions (Live / GitHub / Details) on back.
- **Reusable Components**  
  Clean separation of components (ProjectCard, Skills, Sections).
- **Dynamic Project Data**  
  Projects managed via a centralized data file.
- **Modal-Based Case Studies**  
  View detailed project descriptions without leaving the page.

## 🚀 Installation & Setup

### 📋 Prerequisites

* Node.js (v16+ recommended)
* npm or yarn

### 🛠️ Steps to Run Locally

```bash
# Clone repository
git clone https://github.com/your-username/portfolio.git

# Navigate to project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

The app will run at:
👉 `http://localhost:5173`

## 🎨 Customization

* **Projects**
  Edit `src/data/projectsData.js` to add or update projects.
* **Theme / Colors**
  Update Tailwind config or utility classes.
* **Content Sections**
  Modify components inside `src/components/`.
